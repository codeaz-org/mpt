--- SCRIPT (125 words) ---
Your API keys are public because of how frontend environment variables work. If you type "hide my api key" or "put the key in the .env file" you’ll still see the key in the browser. In Vite apps any variable starting with VITE_ is baked into the JavaScript that the browser downloads. Next.js does the same for NEXT_PUBLIC_. A secret key with that prefix is published to every visitor. The fix is simple: rotate every exposed key, call paid APIs from a server or an Edge Function, and keep only publishable keys in the browser.
