--- SCRIPT (130 words) ---
You can check in one minute whether strangers can trigger your backend function. If anyone can hit that URL, they can send emails or spend credits without your permission. That means your users’ data and your budget are exposed. First, log into your dashboard and list all Edge Functions. For each function, open its code and look for a user token check. If the code simply runs without verifying a valid token, it’s open to the public. Then, add a line that requires a valid user token and confirm the function is set to require authentication in the settings. If it fails, block unauthenticated requests and store secrets in the function’s environment variables. If you’d rather not do it alone, get your app audited at rescue dot codeaz dot org.
