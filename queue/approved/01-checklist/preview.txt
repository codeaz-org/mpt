TOPIC: rls-off -- Launch checklist #1: Row Level Security is on for every table

--- SCRIPT (106 words) ---
Launch checklist, number one: Row Level Security is on for every table. If you leave that off, anyone who opens your app can read every user’s data from the browser console, and no one will notice until someone looks. Turn on Row Level Security for each Supabase table, then write a policy that lets a user see only their own rows. Test by logging out and logging in as a second user to confirm the policy works. If you’d rather not do it alone, you can get your app audited at rescue dot codeaz dot org – a written report in 72 hours, then fixed‑price fixes.
