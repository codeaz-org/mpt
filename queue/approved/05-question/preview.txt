--- SCRIPT (119 words) ---
A founder asked how to prove one tenant can’t read another tenant’s data in Supabase. The issue is that Supabase ships the public key inside every browser, and if Row Level Security (RLS) is off, anyone can query a table and see every row. RLS is the safety switch that blocks those queries unless a rule says otherwise. To fix it, turn RLS on for each table, then write a policy that lets a user see only rows where the user‑id column matches their own ID.
